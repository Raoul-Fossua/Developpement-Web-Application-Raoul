## 📋 Présentation du projet

Ce dépôt contient l'ensemble du projet **To-Do List** développé dans le cadre du cours de Développement Web. 
L'application est entièrement Front-End (HTML, CSS, JavaScript) et utilise l'API **LocalStorage** pour la persistance des données.
